# نظام حصر ومتابعة غياب الطالبات — المتوسطة التاسعة والستون

هذا المجلد يحتوي على موقع ثابت مكوّن من صفحتين، مع مصدر بيانات مجاني عبر Google Sheets.

## الملفات
- `index.html` — الصفحة العامة التي يعبّئها أولياء الأمور.
- `dashboard.html` — لوحة المتابعة الخاصة بالموجهة الطلابية (محمية برمز دخول).
- `style.css` — التصميم المشترك بين الصفحتين.
- `moe-logo.png` — شعار الوزارة (جاهز، مقصوص ومُعد مسبقًا).
- `apps-script.gs` — كود الخادم، يُلصق في Google Apps Script.

الرابطان والرمز مُفعّلون بالفعل داخل الملفات، لا حاجة لإعادة ربطهما:
- تسجيل الغياب: `https://sixty-ninth-intermediate-school.github.io/Sixty-Ninth-Intermediate-School-Attendance/`
- لوحة المتابعة: `https://sixty-ninth-intermediate-school.github.io/Sixty-Ninth-Intermediate-School-Attendance/dashboard.html`
- رمز الدخول: `hayat69school`

## عند رفع هذا التحديث — خطوتان ضروريتان

### ١. تحديث كود Apps Script (وليس مجرد الحفظ)
افتحي محرر Apps Script نفسه (من Google Sheets: الإضافات ← Apps Script)، احذفي الكود القديم بالكامل، وألصقي محتوى `apps-script.gs` الجديد. بعدها **لا تكتفي بالحفظ فقط**:

من أعلى يمين المحرر: Deploy ← Manage deployments ← اضغطي أيقونة القلم (تعديل) بجانب الويب آب الحالي ← من قائمة Version اختاري **New version** ← Deploy.

هذه الخطوة ضرورية في كل مرة يتغيّر فيها الكود، لأن حفظ الملف وحده لا يُحدّث الرابط المنشور فعليًا (وهذا سبب مشكلة التاريخ الغريب التي ظهرت سابقًا).

### ٢. تفريغ بيانات التجربة القديمة من الشيت
لأن هذا التحديث يضيف عمود جديد ("المعرف" — يُستخدم لحذف تسجيل واحد بعينه)، يلزم حذف كل الصفوف التجريبية القديمة حتى لا تسبب تعارضًا: افتحي الشيت (Google Sheet) ← اختاري كل الصفوف تحت رأس الجدول ← Delete rows. بعدها أي تسجيل جديد سيدخل بالترتيب الصحيح ويصبح قابلاً للحذف الفردي.

## رفع الملفات على GitHub
ارفعي كل الملفات الخمسة إلى نفس المستودع الحالي بنفس الأسماء (ستستبدل القديمة تلقائيًا): `index.html`، `dashboard.html`، `style.css`، `moe-logo.png`، وحدّثي كود Apps Script كما بالأعلى (لا يُرفع `apps-script.gs` نفسه لأي مكان، فهو يُستخدم فقط داخل محرر Apps Script).

## ما الجديد في هذا التحديث
- **حذف تسجيل واحد**: من لوحة المتابعة، فتح تفاصيل أي طالبة يُظهر زر "حذف" أمام كل تسجيل غياب على حدة، لحالات الخطأ أو التكرار.
- **منع التسجيل المكرر**: إذا حاول نفس ولي الأمر تسجيل نفس الطالبة (نفس الصف والفصل) في نفس التاريخ مرتين، يرفض النظام التسجيل الثاني ويظهر رسالة توضيحية بدل حفظه.
