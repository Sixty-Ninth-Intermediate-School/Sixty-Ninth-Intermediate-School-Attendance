# نظام حصر ومتابعة غياب الطالبات — المتوسطة التاسعة والستون

هذا المجلد يحتوي على موقع ثابت مكوّن من صفحتين، مع مصدر بيانات مجاني عبر Google Sheets. الإعداد يتم مرة واحدة فقط.

## الملفات
- `index.html` — الصفحة العامة التي يعبّئها أولياء الأمور (تُنشر رابطها لهم).
- `dashboard.html` — لوحة المتابعة الخاصة بالموجهة الطلابية (محمية برمز دخول، لا تُنشر لأولياء الأمور).
- `style.css` — التصميم المشترك بين الصفحتين.
- `apps-script.gs` — الكود الذي يُلصق في Google Apps Script ليكون بمثابة الخادم (backend).

## خطوات الإعداد (تُنفَّذ مرة واحدة)

### ١. إنشاء جدول بيانات Google Sheets
افتحي [sheets.google.com](https://sheets.google.com) وأنشئي جدولاً جديدًا باسم مناسب، مثل "بيانات غياب الطالبات".

### ٢. إضافة كود Apps Script
من داخل الجدول: الإضافات (Extensions) ← Apps Script. احذفي أي كود موجود في الملف، وألصقي محتوى `apps-script.gs` كاملاً. غيّري السطر التالي إلى رمز سري من اختيارك (هذا هو رمز الدخول للوحة المتابعة لاحقًا):

```
const ACCESS_KEY = 'CHANGE_THIS_SECRET_KEY';
```

### ٣. نشر الكود كتطبيق ويب
من أعلى يمين المحرر: Deploy ← New deployment ← اختاري النوع "Web app".
- Execute as: **Me**
- Who has access: **Anyone**

اضغطي Deploy، وفي أول مرة سيطلب منك الموافقة على الأذونات (Authorize access) — هذا طبيعي، وافقي بحساب Google الخاص بالمدرسة.

بعد النشر سيظهر رابط بصيغة:
```
https://script.google.com/macros/s/xxxxxxxxxxxxx/exec
```
انسخي هذا الرابط.

### ٤. ربط الرابط بالصفحتين
افتحي `index.html` و `dashboard.html`، وفي كل منهما استبدلي هذا السطر:
```js
const APPS_SCRIPT_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
```
بالرابط الذي نسختيه، بحيث يصبح مثلاً:
```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxxxxxxxx/exec";
```

### ٥. رفع الملفات على GitHub Pages
1. أنشئي مستودعًا (repository) جديدًا على GitHub.
2. ارفعي الملفات الأربعة: `index.html`، `dashboard.html`، `style.css` (لا حاجة لرفع `apps-script.gs` لأنه يُستخدم فقط داخل محرر Apps Script).
3. من إعدادات المستودع: Settings ← Pages ← فعّلي النشر من الفرع الرئيسي (main) والمجلد الجذر (root).
4. بعد دقيقة أو دقيقتين، سيصبح الموقع متاحًا على رابط بصيغة:
   `https://USERNAME.github.io/REPO-NAME/`

- رابط تسجيل الغياب (لأولياء الأمور): `https://USERNAME.github.io/REPO-NAME/`
- رابط لوحة المتابعة (للموجهة فقط): `https://USERNAME.github.io/REPO-NAME/dashboard.html`

## ملاحظات مهمة
- **الخصوصية**: صفحة `dashboard.html` محمية برمز الدخول الذي حددتِه في `ACCESS_KEY`، ولا تُشارَك مع أولياء الأمور مطلقًا. يُنصح بعدم مشاركة الرابط في أي مكان عام.
- **المرفقات**: عند إرفاق ولي الأمر ملفًا (كصورة موعد المستشفى)، يُحفظ تلقائيًا في مجلد باسم "مرفقات غياب الطالبات" داخل Google Drive الخاص بحساب المدرسة.
- **حدود الاستخدام**: خدمة Apps Script مجانية بالكامل ولها حد يومي سخي (عشرات الآلاف من الطلبات يوميًا)، وهو أكثر من كافٍ لمدرسة واحدة.
- **حدود المرفقات**: حجم الملف الواحد يُفضّل ألا يتجاوز ٥ ميغابايت تقريبًا لضمان سرعة الرفع.
- عتبات الألوان (🟢🟡🟠🔴) في لوحة المتابعة قابلة للتعديل داخل `dashboard.html` (دالة `statusFor`) حسب سياسة المدرسة.
